# Tekstowy RPG

## Opis projektu

**Tekstowy RPG** to gra fabularna, w której gracz poznaje świat i historię za pomocą opisów tekstowych. Podejmowane decyzje wpływają na przebieg przygody oraz jej zakończenie.

## Rozgrywka

Gracz czyta kolejne fragmenty opowieści, wybiera dostępne opcje i rozwija swoją postać. Każda decyzja może prowadzić do innego wydarzenia, wyzwania lub zakończenia.

## Cel projektu

Celem projektu jest stworzenie prostej i angażującej gry RPG działającej w całości w formie tekstowej.
